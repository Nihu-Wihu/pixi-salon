# pixi-salon
This is a project I made on p5.js. With only JavaScript. It is a salon where you can change your avatar's hair, skin, background, shirt, and bangs! 

link to DEMO --> https://nihu-wihu.github.io/pixi-salon/

link to p5.js --> https://editor.p5js.org/jagadeesha.2/sketches/D_UZH96cp

### Project Requirements
Your project should:
- Include at least six shapes. 
- Include at least three colors.
- Include at least one clearly named variable that stores a feature of your avatar. 
- Include at least one conditional statement.
- Include mouse interaction.
